# dentistry

Сайт медицинской клиники «Улыбка».

## Что использовал
- HTML: семантическая верстка, формы
- CSS: Flexbox, тени, рамки, эффекты при наведении
- CSS: типографика (шрифты, цвета, отступы)

## Особенности проекта
- Шапка с крупным номером телефона
- Главный экран с призывом к действию
- Блок преимуществ на темном фоне
- Услуги с ценами в виде карточек
- Форма записи на прием
